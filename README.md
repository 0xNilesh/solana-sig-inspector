# Solana Sig Inspector

Solana Sig Inspector is a tool to extract and sign messages with Solana wallets.

## Features

- **Extract**: Extract signature components from a transaction.
- **Sign**: Sign a message with your wallet and view the signature in both Hex and Base58 formats.

## Installation

1. Clone the repo:
```
git clone https://github.com/yourusername/solana-sig-inspector.git
```

2. Install dependencies:
```
npm install
```

3. Run the app:
```
npm run dev
```

## Usage

- **Extract**: Input a Solana transaction hash to extract message bytes, signature, and public key.
- **Sign**: Input a message and sign it with your wallet. View the signed message in both Hex and Base58 formats.
